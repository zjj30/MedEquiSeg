\section*{COVID-19 grouped train--validation sensitivity}
The fixed public test set is unchanged in this analysis. Recoverable subject
tokens are assigned to only one training or validation split; rows without a
recoverable token remain case-level groups. This is a split-sensitivity analysis,
not evidence that every image in the source release has a known patient identity.

\input{paper/latex/bmc_work_public5/bmc_covid_groupval_table.tex}
\FloatBarrier

Within the grouped-validation checkpoint set, the direct \methodname{} minus
\norewrite{} Dice contrast is $-0.29$ percentage points (paired-case 95\%
confidence interval $-0.55$ to $-0.03$). After equal-subject averaging over 474
recoverable subjects, the effect is $-0.40$ points; the subject-cluster interval
is $-0.58$ to $-0.02$ and the two-sided Wilcoxon $p$-value is $<.001$. The
grouped sensitivity therefore does not rescue an accuracy-benefit claim for
rewriting.

\section*{Presence/class-stratified prompt derangement}
This post hoc sensitivity analysis reuses the 15 frozen complete-model
checkpoints and performs no retraining. For each public dataset, the complete
test-prompt multiset is deterministically permuted within target-presence and
diagnostic-class strata constructed from released case identifiers and prompt
fields. The control builder reads neither image pixels nor masks and validates
one-to-one prompt closure, donor identity, stratum membership, and text hashes.
It changes 3,413 of 3,426 prompt strings; the 13 unavoidable unchanged cases are
BUSI normal studies whose within-stratum strings are identical. Statistics first
average the three checkpoint values for each case, then use paired 10,000-repeat
bootstrap intervals and Holm-adjusted Wilcoxon tests. The analysis remains a
privileged-prompt diagnostic because the strata and prompts encode released
target-derived information.
