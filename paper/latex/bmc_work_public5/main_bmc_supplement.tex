\section*{Layer-resolved MedEquiSeg architecture}
The main manuscript shows the effective forward graph at a readable scale.
The following two figures expose the source-verified layer transitions and
custom operators. They do not add dormant modules or token-level fusion to the
evaluated graph.

\begin{figure}[p]
\centering
\includegraphics[width=\linewidth,keepaspectratio]{paper/figures/medequiseg_layer_details_supp_v1.pdf}
\caption{Layer-resolved encoder and text representation. (A) The fine-tuned
OpenAI CLIP-RN50 stage stack, anti-aliased bottleneck, and spatial-only
AttentionPool2d implementation. (B) The three multi-scale alignment routes and
the CARAFE reassembly operator. (C) The complete frozen BioMedCLIP text tower,
the boundary between one-time cache construction and online lookup, and the
trainable pooled-feature adapter. BioMedCLIP contributes a pooled 512-D vector;
token-level text fusion is inactive.}
\label{fig:supp-layer-details}
\end{figure}

\begin{figure}[p]
\centering

identical but independently parameterized Masker; supportive and inferior
features are complementary, and their three-scale aggregation uses shared
weights. (E) The two projectors are parameter-independent and each contains one
active ATConv followed by a text-conditioned per-sample dynamic classifier.
(F) ATConv's visual kernel and feature branches. The pooled semantic state does
not enter ATConv itself.}

\section*{Presence/class-stratified prompt derangement}
This post hoc sensitivity analysis reuses the 15 trained complete models
without retraining. For each public dataset, the complete
test-prompt multiset is deterministically permuted within target-presence and
diagnostic-class strata constructed from released case identifiers and prompt
fields. The permutation uses neither image pixels nor masks and preserves
one-to-one prompt assignment, donor identity, stratum membership, and prompt-text
consistency.
It changes 3,413 of 3,426 prompt strings; the 13 unavoidable unchanged cases are
BUSI normal studies whose within-stratum strings are identical. Statistics first
average the three model values for each case, then use paired 10,000-repeat
bootstrap intervals and Holm-adjusted Wilcoxon tests. The analysis remains a
privileged-prompt diagnostic because the strata and prompts encode released
target-derived information.

\section*{Targeted matched prompt-rewrite control}
To estimate prompt rewriting under a fixed shared augmentation policy, two BUSI
arms were newly trained for 100 epochs with seeds 123, 456, and 789. Within each
seed pair, the fixed partition, pretrained initialization, pooled BioMedCLIP
cache, model recipe, and deterministic image--mask augmentation plan were held
constant; only spatial-phrase rewriting after flips and right-angle rotations
differed. This targeted control is separate from the 75-run ordered matrix and
does not estimate an across-dataset rewriting effect or the effect of shared
augmentation itself.
